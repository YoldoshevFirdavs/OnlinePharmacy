TROUBLESHOOTING QUICK REFERENCE
================================================================================

If messages.js doesn't load:
   → Check: static/js/messages.js exists
   → Run: python manage.py collectstatic
   → Verify: Browser shows no 404 for /static/js/messages.js

If contact form returns 404:
   → Check URL: /api/v1/products/contact/ (not /api/v1/contact/)
   → Verify: pharmacy app URLs configured correctly
   → Test: curl -X POST http://localhost:8000/api/v1/products/contact/

If popular products returns 404:
   → Check URL: /api/v1/products/popular/?range=30
   → Verify: pharmacy app URLs configured correctly

If Swagger returns 404:
   → Check: drf_yasg installed (pip list | grep drf-yasg)
   → Verify: /swagger/ in urls.py
   → Add ALLOWED_HOSTS: testserver (for testing)

If role-based messages not working:
   → Check: body has data-user-role attribute
   → Verify: User is_staff status in database
   → Test: messages.error("Test error") in console
