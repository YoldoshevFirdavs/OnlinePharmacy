QUICK DEPLOYMENT (5 MINUTES):
═════════════════════════════════════════════════════════════════════════════

1. SSH to EC2:
   ssh -i your-key.pem ec2-user@your-ec2-ip

2. Go to project:
   cd /home/ec2-user/OnlinePharmacy

3. Prepare host directories:
   bash DOCKER_HOST_SETUP.sh

4. Edit environment variables:
   nano .env.prod
   (Set: DB_NAME, DB_USER, DB_PASSWORD, SECRET_KEY, ALLOWED_HOSTS)

5. Build Docker image:
   docker compose -f docker-compose.prod.yml build

6. Start all services:
   docker compose -f docker-compose.prod.yml up -d

7. Run initial setup:
   docker compose -f docker-compose.prod.yml exec web python manage.py migrate
   docker compose -f docker-compose.prod.yml exec web python manage.py collectstatic --noinput
   docker compose -f docker-compose.prod.yml exec web python manage.py createsuperuser

8. Verify deployment:
   docker compose -f docker-compose.prod.yml ps
   curl http://localhost:8000/api/v1/health/
   ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/

Done! ✅

VOLUME MOUNTS - HOW IT WORKS:
═════════════════════════════════════════════════════════════════════════════

docker-compose.prod.yml defines:

  volumes:
    - /home/ec2-user/OnlinePharmacy/staticfiles:/app/staticfiles
    - /home/ec2-user/OnlinePharmacy/media:/app/media
    - /home/ec2-user/OnlinePharmacy/postgres_data:/var/lib/postgresql/data/

This means:
  • When Django writes to /app/staticfiles inside container
  • File actually goes to /home/ec2-user/OnlinePharmacy/staticfiles on host
  • You can SSH to EC2 and see the file immediately
  • Nginx can read directly from host (if enabled)

Example:
  1. User uploads avatar in browser
  2. Django saves to: /app/media/uploads/avatars/user.jpg
  3. File appears at: /home/ec2-user/OnlinePharmacy/media/uploads/avatars/user.jpg
  4. You can: ssh to EC2 and ls -la /home/ec2-user/OnlinePharmacy/media/uploads/avatars/
  5. File is there! ✓ No docker cp needed!

TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════════════════

PROBLEM: Container won't start
  docker compose logs web
  Check .env.prod for typos/missing values

PROBLEM: Static files 404
  docker compose exec web python manage.py collectstatic --noinput
  ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/

PROBLEM: Media uploads fail
  mkdir -p /home/ec2-user/OnlinePharmacy/media
  chmod -R 755 /home/ec2-user/OnlinePharmacy/media

PROBLEM: Database connection error
  docker compose logs db
  Check DB_PASSWORD matches POSTGRES_PASSWORD

For detailed troubleshooting: DOCKER_PROD_DEPLOYMENT.md
