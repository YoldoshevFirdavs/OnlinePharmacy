HOW IT WORKS (In 30 Seconds):
═════════════════════════════════════════════════════════════════════════════

1️⃣  You run setup script on EC2 HOST:
    bash DOCKER_HOST_SETUP.sh
    ├─ Creates directories (staticfiles, media, postgres_data)
    ├─ Runs collectstatic on HOST (not Docker)
    └─ Static files on host: /home/ec2-user/OnlinePharmacy/staticfiles/

2️⃣  Docker starts:
    docker compose -f docker-compose.prod.yml up -d
    ├─ Mounts host directories to containers
    ├─ Runs migrations
    ├─ Starts Gunicorn
    └─ NO collectstatic inside Docker ✓

3️⃣  Browser requests static file:
    curl http://localhost/static/css/main.css
    ├─ Nginx reads from: /home/ec2-user/OnlinePharmacy/staticfiles/
    ├─ Serves it directly
    └─ Done! ✓

RESULT: Everything on host, Docker just runs the app!

QUICK DEPLOYMENT (5 STEPS):
═════════════════════════════════════════════════════════════════════════════

1. SSH to EC2:
   ssh -i your-key.pem ec2-user@your-ip

2. Go to project:
   cd /home/ec2-user/OnlinePharmacy

3. Run setup (creates dirs + collects static):
   bash DOCKER_HOST_SETUP.sh

4. Start Docker:
   docker compose -f docker-compose.prod.yml build
   docker compose -f docker-compose.prod.yml up -d

5. Initialize:
   docker compose exec web python manage.py migrate
   docker compose exec web python manage.py createsuperuser

Done! ✅

KEY CONCEPTS:
═════════════════════════════════════════════════════════════════════════════

🔑 Static Files Collected On HOST:
   • BEFORE: Docker runs collectstatic
   • AFTER: EC2 host runs collectstatic via DOCKER_HOST_SETUP.sh
   • BENEFIT: Files always visible on host, faster, simpler

🔑 Volume Mounts (Host Paths):
   • /home/ec2-user/OnlinePharmacy/staticfiles → /app/staticfiles (read-only)
   • /home/ec2-user/OnlinePharmacy/media → /app/media (read-write)
   • /home/ec2-user/OnlinePharmacy/postgres_data → PostgreSQL data
   • BENEFIT: All files directly on host, no Docker export needed

🔑 No collectstatic in Docker:
   • entrypoint.sh skips collectstatic
   • Docker only runs: migrations + Gunicorn
   • BENEFIT: Faster startup, simpler entrypoint

STEP-BY-STEP (DETAILED):
═════════════════════════════════════════════════════════════════════════════

1. SSH to EC2:
   ssh -i your-key.pem ec2-user@your-ec2-ip

2. Check prerequisites:
   python --version        # Should be 3.10+
   docker --version        # Should work
   docker compose --version # Should work

3. Go to project:
   cd /home/ec2-user/OnlinePharmacy

4. Create/update .env.prod with your values:
   nano .env.prod
   
   Required:
     DB_NAME=onlinepharmacy_prod
     DB_USER=pharmacy_user
     DB_PASSWORD=strong-password-16-chars-min
     SECRET_KEY=long-random-string-64-chars-min
     ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com
     DEBUG=False

5. Run setup (creates dirs + collects static):
   bash DOCKER_HOST_SETUP.sh
   
   Expected:
     ✅ staticfiles created
     ✅ media created
     ✅ postgres_data created
     ✅ Collecting static files...
     123 static files copied to...
     ✅ collectstatic completed successfully

6. Verify static files on host:
   ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/
   
   Should see: admin/, css/, js/, images/

7. Build Docker image:
   docker compose -f docker-compose.prod.yml build

8. Start all services:
   docker compose -f docker-compose.prod.yml up -d

9. Check status:
   docker compose -f docker-compose.prod.yml ps
   
   All services should show "Up"

10. Run migrations:
    docker compose -f docker-compose.prod.yml exec web python manage.py migrate

11. Create superuser:
    docker compose -f docker-compose.prod.yml exec web python manage.py createsuperuser

12. Test API:
    curl http://localhost:8000/api/v1/health/
    
    Should return: HTTP 200 OK

13. Test static files:
    curl -I http://localhost:8000/static/css/main.css
    
    Should return: HTTP 200 OK

Done! ✅ Your app is running!

TROUBLESHOOTING (5 QUICK FIXES):
═════════════════════════════════════════════════════════════════════════════

❌ Static files 404:
   ✅ docker compose exec web python manage.py collectstatic --noinput

❌ Media uploads not working:
   ✅ mkdir -p /home/ec2-user/OnlinePharmacy/media
   ✅ chmod -R 755 /home/ec2-user/OnlinePharmacy/media

❌ Database connection error:
   ✅ docker compose logs db
   ✅ Check: DB_PASSWORD = POSTGRES_PASSWORD in .env.prod

❌ Python not found on host:
   ✅ pip install -r requirements.txt

❌ Container won't start:
   ✅ docker compose logs web
