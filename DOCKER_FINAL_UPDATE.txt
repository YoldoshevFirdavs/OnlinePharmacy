KEY CONCEPT: Static Files Collection on HOST, NOT Docker
═════════════════════════════════════════════════════════════════════════════

BEFORE (❌ Old):
  1. Docker starts
  2. entrypoint.sh runs collectstatic inside container
  3. Files written to Docker volume
  4. Files must be exported/mounted to host
  → Complex, files hidden inside Docker

AFTER (✅ New):
  1. Run DOCKER_HOST_SETUP.sh on EC2 host
  2. Script creates directories + runs collectstatic on host
  3. All static files directly on /home/ec2-user/OnlinePharmacy/staticfiles/
  4. Docker mounts that directory (read-only)
  5. Docker just runs app, uses existing static files
  → Simple, files visible on host

FLOW DIAGRAM:
═════════════════════════════════════════════════════════════════════════════

STEP 1 - On EC2 Host (Before Docker):
  bash DOCKER_HOST_SETUP.sh
  ├─ Creates /home/ec2-user/OnlinePharmacy/staticfiles/
  ├─ Creates /home/ec2-user/OnlinePharmacy/media/
  ├─ Creates /home/ec2-user/OnlinePharmacy/postgres_data/
  ├─ Runs: python manage.py collectstatic --noinput
  └─ Result: All static files on host ✓

STEP 2 - Docker Starts:
  docker compose -f docker-compose.prod.yml up -d
  ├─ Mounts /home/ec2-user/.../staticfiles → /app/staticfiles (READ-ONLY)
  ├─ Mounts /home/ec2-user/.../media → /app/media (READ-WRITE for uploads)
  ├─ Mounts /home/ec2-user/.../postgres_data → /var/lib/postgresql/data/
  ├─ Runs migrations
  └─ Starts Gunicorn (NO collectstatic)

STEP 3 - Usage:
  Browser → /static/css/main.css
           ↓
  Nginx serves from: /home/ec2-user/.../staticfiles/static/css/main.css
  ✓ No Docker involved, direct filesystem access

INSTALLATION SEQUENCE:
═════════════════════════════════════════════════════════════════════════════

1. SSH to EC2
   ssh -i your-key.pem ec2-user@your-ec2-ip

2. Go to project
   cd /home/ec2-user/OnlinePharmacy

3. Run host setup (creates dirs + collects static)
   bash DOCKER_HOST_SETUP.sh

4. Verify static files collected
   ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/
   Expected: admin/, css/, js/, images/ directories

5. Edit .env.prod
   nano .env.prod

6. Build Docker image
   docker compose -f docker-compose.prod.yml build

7. Start Docker
   docker compose -f docker-compose.prod.yml up -d

8. Run migrations & create admin
   docker compose exec web python manage.py migrate
   docker compose exec web python manage.py createsuperuser

9. Test
   curl http://localhost:8000/api/v1/health/
   curl -I http://localhost:8000/static/css/main.css

VOLUME MOUNTS (docker-compose.prod.yml):
═════════════════════════════════════════════════════════════════════════════

web:
  volumes:
    - /home/ec2-user/OnlinePharmacy/staticfiles:/app/staticfiles
    - /home/ec2-user/OnlinePharmacy/media:/app/media

postgres_data:
  driver_opts:
    device: /home/ec2-user/OnlinePharmacy/postgres_data

HOW IT WORKS:
  • /app/staticfiles inside container = /home/ec2-user/.../staticfiles on host
  • Files on host are DIRECTLY accessible on host
  • Nginx serves directly from host (when enabled)
  • Docker reads existing staticfiles (doesn't create them)

═════════════════════════════════════════════════════════════════════════════

WHAT DOCKER DOES:
═════════════════════════════════════════════════════════════════════════════

entrypoint.sh (inside Docker):
  ✅ Run migrations
  ✅ Start Gunicorn
  ❌ NO collectstatic
  ❌ NO static file collection
  ❌ NO file copying

Why?
  Collectstatic already ran on host via DOCKER_HOST_SETUP.sh
  Docker just mounts existing files
  Saves time, simpler, files always visible on host

✅ SCALABILITY
   • Multiple containers can share same static files
   • No need to recollect for each container

TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════════════════

Problem: "Python not found on host"
Solution: Install Python and requirements
  sudo apt-get install python3 python3-pip
  pip install -r requirements.txt

Problem: Static files not collected
Solution: Run manually
  cd /home/ec2-user/OnlinePharmacy
  python manage.py collectstatic --noinput

Problem: .env.prod not found
Solution: Create it
  cp .env.example /home/ec2-user/OnlinePharmacy/.env.prod
  nano /home/ec2-user/OnlinePharmacy/.env.prod

Problem: Permission denied
Solution: Fix permissions
  chmod -R 755 /home/ec2-user/OnlinePharmacy/staticfiles
  chmod -R 755 /home/ec2-user/OnlinePharmacy/media
