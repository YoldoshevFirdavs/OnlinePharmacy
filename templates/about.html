Biz kimlarmiz?

OnlinePharmacy — bu Komiljon Hamidjonovning 10.3 Python Backend kursida Yoldashev Firdavs tomonidan yaratilgan to‘liq stack e-commerce loyihasidir. Loyiha Django, Django REST Framework, PostgreSQL, Redis va Docker texnologiyalari asosida ishlab chiqilgan.

Bizning asosiy maqsadimiz — zamonaviy web dasturlash ko‘nikmalarini mustahkamlash hamda farmatsevtika sohasidagi raqamli yechimlarning imkoniyatlarini namoyish etishdir. Platforma foydalanuvchilarga ro‘yxatdan o‘tish, OTP orqali tasdiqlash, mahsulotlar katalogini ko‘rish, savatga qo‘shish va buyurtma berish imkoniyatini beradi.

2026-yilda boshlangan ushbu loyiha nafaqat kod yozish, balki to‘liq ishlaydigan, xavfsiz va foydalanuvchiga qulay tizim yaratish tajribasini oshirish uchun ishlab chiqildi. Hozirgi vaqtda loyiha o‘quv maqsadida ishlatilmoqda va tijorat maqsadida foydalanilmaydi.

Bizning Maqsad va Qadriyatlarimiz

Missiya

Sog‘liqni saqlash jarayonini har bir inson uchun qulay, shaffof va tezkor qilish. Talaba sifatida biz zamonaviy texnologiyalar yordamida real dunyo muammolariga yechim taklif qilishni o‘rganmoqdamiz.

Biz nima qurdik?

OnlinePharmacy loyihasi to‘liq funksional e-commerce platforma bo‘lib, quyidagi imkoniyatlarni o‘z ichiga oladi:

  • JWT autentifikatsiya + OTP tasdiqlash tizimi
  • Mahsulotlar katalogi, qidiruv va filtrlar
  • Savat va buyurtmalar tizimi
  • Celery orqali email xabarnomalar
  • Redis caching va sessiya boshqaruvi
  • Admin panel va analitika

Texnologiya stacki:

Django 5.1 Django REST Framework PostgreSQL Redis Celery Docker Nginx + Gunicorn Vanilla JS

Xavfsizlik nuqtai nazaridan: PBKDF2 parol hash, JWT token expiry (1 soat), refresh token (7 kun), OTP TTL (10 daqiqa) va boshqa zamonaviy himoya choralari qo‘llanilgan.

Ma’lumotlaringizni qanday himoya qilamiz?

Bu loyiha o‘quv maqsadida yaratilgan. Foydalanuvchi ma’lumotlari (email, telefon, manzil) faqat loyiha doirasida ishlatiladi va hech qachon uchinchi shaxslarga berilmaydi. Barcha ma’lumotlar shifrlangan holda saqlanadi.
