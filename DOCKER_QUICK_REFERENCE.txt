VOLUME MOUNTS (How files are shared)
================================================================================

DOCKER CONTAINER              HOST FILESYSTEM
─────────────────────────────────────────────────────────────────────────────

/app/media            ←→   /home/ec2-user/OnlinePharmacy/media

  data

KEY POINT: Files written inside Docker are directly accessible on host!
Example: collectstatic writes to /app/staticfiles, which is /home/ec2-user/.../staticfiles on host

================================================================================
DEPLOYMENT STEPS (Copy & Paste)
================================================================================

# 1. SSH into EC2
ssh -i your-key.pem ec2-user@your-ec2-ip

# 2. Go to project
cd /home/ec2-user/OnlinePharmacy

# 3. Create host directories
bash DOCKER_HOST_SETUP.sh

# 4. Update .env.prod with your settings
nano .env.prod
# Edit: DB_NAME, DB_USER, DB_PASSWORD, SECRET_KEY, ALLOWED_HOSTS

# 5. Build Docker images (5-10 min)
docker compose -f docker-compose.prod.yml build

# 6. Start services
docker compose -f docker-compose.prod.yml up -d

# 7. Check status
docker compose -f docker-compose.prod.yml ps

# 8. Create superuser
docker compose -f docker-compose.prod.yml exec web python manage.py createsuperuser

# 9. Collect static files
docker compose -f docker-compose.prod.yml exec web python manage.py collectstatic --noinput

# 10. Verify
curl http://localhost:8000/api/v1/health/
ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/

================================================================================
COMMON COMMANDS (Copy & Paste)
================================================================================

# VIEW LOGS
docker compose -f docker-compose.prod.yml logs -f web              # Follow web logs
docker compose -f docker-compose.prod.yml logs -f db               # Follow db logs
docker compose -f docker-compose.prod.yml logs web | tail -100     # Last 100 lines

# EXECUTE COMMANDS IN CONTAINER
docker compose -f docker-compose.prod.yml exec web bash            # Shell access
docker compose -f docker-compose.prod.yml exec web python manage.py shell
docker compose -f docker-compose.prod.yml exec web python manage.py migrate

# RESTART SERVICES
docker compose -f docker-compose.prod.yml restart                  # Restart all
docker compose -f docker-compose.prod.yml restart web              # Restart just web
docker compose -f docker-compose.prod.yml restart db               # Restart just db

# STOP/START
docker compose -f docker-compose.prod.yml stop                     # Stop (keep data)
docker compose -f docker-compose.prod.yml down                     # Stop (remove containers)
docker compose -f docker-compose.prod.yml up -d                    # Start again

# DATABASE OPERATIONS
docker compose -f docker-compose.prod.yml exec db psql -U pharmacy_user -d onlinepharmacy_prod
docker compose -f docker-compose.prod.yml exec db pg_dump -U pharmacy_user -d onlinepharmacy_prod > backup.sql

# STATIC FILES
docker compose -f docker-compose.prod.yml exec web python manage.py collectstatic --noinput
ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/

# SYSTEM STATUS
docker compose -f docker-compose.prod.yml ps                       # Container status
docker stats                                                        # CPU/Memory usage
df -h /home/ec2-user/                                              # Disk space

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Container won't start
SOLUTION:
  docker compose -f docker-compose.prod.yml logs web
  docker compose -f docker-compose.prod.yml ps

ISSUE: Static files return 404
SOLUTION:
  docker compose -f docker-compose.prod.yml exec web python manage.py collectstatic --noinput
  ls -la /home/ec2-user/OnlinePharmacy/staticfiles/static/
  chmod -R 755 /home/ec2-user/OnlinePharmacy/staticfiles

ISSUE: Media uploads not working
SOLUTION:
  mkdir -p /home/ec2-user/OnlinePharmacy/media
  chmod -R 755 /home/ec2-user/OnlinePharmacy/media
  docker compose -f docker-compose.prod.yml restart web

ISSUE: Database connection error
SOLUTION:
  docker compose -f docker-compose.prod.yml logs db
  docker compose -f docker-compose.prod.yml ps db
  Check: grep DB_NAME /home/ec2-user/OnlinePharmacy/.env.prod

ISSUE: Out of disk space
SOLUTION:
  du -sh /home/ec2-user/OnlinePharmacy/*
  find /home/ec2-user/OnlinePharmacy/media -type f -mtime +90 -delete
